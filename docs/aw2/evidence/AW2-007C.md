## Implemented contract and IDs

`src/aw2/world/encounter.ts` keeps the real combat state in a private WeakMap. Consumers receive detached snapshots and may issue only tick/ultimate/retreat commands. Factory reads a strict schema v3 checkpoint directly, derives battle identity from its saveId/revision and always creates the same canonical development encounter. It accepts no arbitrary combat state or requested win flag. `Aw2DevSaveStore.beginBoss` validates current accepted quest, party/range and writes a safe checkpoint before returning a live encounter. `finishBoss` accepts a registered authentic terminal/retreat bound to that exact raw checkpoint; Web Locks and raw comparison serialize writes. Normal `save` cannot introduce a boss win. Save failure preserves the terminal for retry; changed/reset storage refuses stale results.

Canonical encounter `aw2-enemy-forgotten-host`, quest `aw2-quest-one-more-bowl`, note object `aw2-object-table-note`, choices `aw2-choice-seat-wait` / `aw2-choice-seat-share`, derived completion receipt `aw2-grant-one-more-bowl`. The five canonical starters and their immutable identity/skill/asset IDs are unchanged. Completion remains a monotonic quest marker, not a numerical inventory grant. New shortcut objects `aw2-shortcut-yard-table` / `aw2-shortcut-table-yard` are reciprocal, gated on final completion and use safe spawn96,192.

Save v3 adds strict `bossDefeated`, `tableNoteRead` and `endingChoice`; questIndex4 represents completion with accepted=false, boss/note=true and one ending. Valid1/2 migrate only in memory with old identity/timestamps/progress intact until an explicit write. Invalid/future schemas remain preserved. Defeat/retreat preserves prior objectives and returns to Sân; win returns to safe Phòng Bàn. Reload/reread discards an uncommitted encounter at its saved checkpoint and never grants victory. Active battle state is not persisted/resumed.

`WorldBattle.tsx` uses stable command callbacks, a ref for latest presentation, effect cleanup for its timer and no side effects inside React state updaters. World input/dialog/travel are unmounted/paused during battle. Canvas reads results only; canonical enemy explicitly maps to a tinted Than reference atlas and label.
