## Contract and implementation

One AW2-only adapter connects `tcg` / `auto-chess` through approved `aw2-npc-ban-bai` / `aw2-npc-ban-co` street portals or world-menu quick-entry. Portal validates canonical mode/object/zone/range and valid exploration; quick-entry needs a ready AW2 save with no added quest/tier/payment gate. Explicit entry commits current safe position using existing raw comparison/Web Locks. Failure/stale/concurrent entry mounts no lobby. Pending/active visit and active world battle block nested entry; late activity changes cannot mount a lobby after checkpointing.

Private session checkpoint bytes are independent of detached renderer metadata. Return reads the same ready checkpoint without a second write/reward; changed/reset/missing/corrupt/future saves require reread. Reread discards transient mode state; reload returns to saved exploration, not a resumed game/victory. Pure world action `visit-mode` rejects, requiring the adapter. Lobby discloses that actual games/prizes are not integrated. **Parent AW2-009/full playable MODE-01 remain open.**
