## Kết quả kỹ thuật

Production AW2 nay tải `WebUpdatePrompt` song song với game route, nên waiting worker có UI cập nhật thật thay vì chỉ hoạt động ở Rương/main cũ. Menu Hướng dẫn có bảng PWA compact: online/offline, readiness, media cache bytes/entries, browser usage/quota, previous cache count, kiểm tra update, explicit update/reload, install prompt và persistent-storage request. `beforeinstallprompt` chỉ được gọi sau click; dismissed prompt không bị gọi lại; standalone/appinstalled không tiếp tục mời cài.

Service worker xóa core version cài dở nếu `addAll` lỗi, fallback navigation từ current shell sang previous shell, giữ hashed chunk cho tab cũ và chỉ giữ tối đa một previous core/media. Media LRU trim trước khi ghi theo60MB/120entry; nếu browser vẫn từ chối `cache.put`, worker evict thêm một entry và retry đúng một lần. Cache status đi qua `MessagePort`; worker không đọc/ghi localStorage, IndexedDB hay save AW2.

Manifest production có `id`/`scope` `/`, standalone, tiếng Việt, icon192/512 và chỉ hai shortcut `/` + `/chest`. Package verifier đọc chính artifact để chặn manifest sai.
