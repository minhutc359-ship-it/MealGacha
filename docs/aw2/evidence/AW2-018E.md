# AW2-018E — Save durability, migration và recovery

VERIFIED_DEVELOPMENT_WITH_LIMITATION · 19/20 · batch3/10 · 2026-10-28 · base remote `f33f3a355cb2d2fa3a0b6a2cd70ca1bfd2a0909c`.

## Kết quả kỹ thuật

Browser localStorage AW2 nay dùng bốn key cùng namespace: main, backup, journal và quarantine. Mỗi lần ghi vẫn nằm trong Web Lock và exact-raw compare; main hợp lệ trước đó được read-back vào backup, candidate được read-back trong journal, main mới được read-back trước khi trả thành công. Storage no-op/quota/denied không còn có thể tạo success giả. Journal còn sót không được áp dụng khi main hợp lệ; main trống nhưng có candidate sẽ chặn tạo save mới.

`inspectRecovery` chỉ đưa ra candidate schema hiện hành khi main empty/invalid, chọn xác định theo thời gian/revision và không rollback `unsupported`. `recover` khóa lại, kiểm tra exact main/source/candidate, quarantine bytes lỗi, ghi/read-back main và dọn journal. Production `WorldGame`, world review và công cụ save đều có nút phục hồi explicit; storage event trên cả bốn key buộc tab cũ đọc lại. Migration1–7→8 vẫn read-only cho tới thao tác lưu.

[Runbook save/recovery](../SAVE_RECOVERY.md).
