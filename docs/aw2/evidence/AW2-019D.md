## Defect and cause

The merge commit and `rpg` parent have the same tree, and a complete checkout passes `pnpm build`. The committed `.vercelignore`, however, contained `dev/` and `rights/`. Applying that deployment filter removed the first build entry point and reproduced the supplied failure exactly:

```text
Error: Cannot find module '/tmp/mealgacha-vercel-input.WJ7gUG/dev/tools/verify-aw2-source-checkout.mjs'
    at Module.executeUserEntryPoint [as runMain] (node:internal/modules/run_main:154:5)
    at node:internal/main/run_main_module:33:47 {
  code: 'MODULE_NOT_FOUND',
  requireStack: []
}
Node.js v24.22.1
```

`rights/` would also have removed the records required by the next character/media checks. This is a deployment-input defect, not a Vite, pnpm or gameplay failure.

## Repair

- `.vercelignore` now permits only `node_modules/`, `dist/`, `dist-aw2/`, `.asset-work/`, `*.log` and `*.tsbuildinfo`; production `dev/` and `rights/` remain in the build input.
- The delivery contract rejects duplicates, missing approved rules and every unapproved ignore rule.
- Focused tests explicitly reject `dev/` and `rights/` regressions.
- Production package verification and the candidate `delivery-security` gate validate the same ignore contract.
