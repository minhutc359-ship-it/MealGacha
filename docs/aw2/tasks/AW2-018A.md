2. `/` mở trực tiếp fixed-viewport game shell mới, không redirect qua trang thử nghiệm.
3. `/game`, `/adventure`, `/autochess`, `/pvp` và các URL main cũ đều vào AW2, không mount trang cũ.
4. Chỉ `/chest` và `/chest/` mở Rương Vị Giác original.
5. Rương dùng store/catalog/opening/reveal/audio original và giữ nguyên namespace `foodchest.user.v1`.
6. Shell rương production không đưa top-nav/bottom-nav/rail của main cũ trở lại.
7. Rương có lối rõ ràng quay về hành trình mới; hành động cũ không mở lại collection/quiz/events pages.
8. Game shell production bỏ nhãn/link công cụ phát triển, nhưng review `world.html/game.html` vẫn hoạt động.
9. Empty/error state production dùng ngôn ngữ người chơi và không trỏ `/dev/aw2`.
10. AW2 runtime asset URL được đổi từ `/dev/aw2/assets` sang `/assets/aw2` trong build production.
11. Build copy đúng WebP/WAV/JSON runtime, loại PNG source, file ẩn/tạm, TS/TSX/map/archive.
12. Release guard chạy trên artifact mới và không cần nới lỏng bảo vệ source/credential.
13. Service worker đóng gói shell mới, route chest và chunk động theo cùng version; không xóa player storage.
14. Vercel tiếp tục dùng `pnpm build` + `dist` + SPA fallback nên server tự nhận cutover.
15. Stable save keys và AW2 save key tách biệt; vào game/rương không tự reset hoặc ghi đè dữ liệu bên kia.
16. `pnpm build:aw2` tiếp tục tạo review artifact nhiều entry cho QA, không bị production cutover phá vỡ.
17. Unit/contract tests khóa route allowlist, entry, asset rewrite/copy exclusions và server config.
18. Source+compiled browser xác minh root/game/chest/legacy fallback, save sentinels, reload và không lỗi bất ngờ.
