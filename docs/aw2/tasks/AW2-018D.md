# AW2-018D — PWA install, update và offline recovery

VERIFIED_DEVELOPMENT_WITH_LIMITATION · 19/20 · batch2/10 · base remote `09041839dcd772b9740a4ed04ddd2c9edf6a3285` · 2026-10-28.

AW2-018C đã tách scene delivery và cold shell. Lát cắt này đóng đường vận hành PWA trên chính game production: người chơi nhìn thấy trạng thái mạng/cache/cài đặt, chủ động cập nhật, và vẫn có đường phục hồi khi cache cài dở, quota thiếu hoặc tab cũ cần chunk của phiên bản trước.

## 20 kế hoạch / tiêu chí nghiệm thu

1. AW2 production hiển thị prompt khi service worker có bản mới; không chỉ Rương/main cũ.
2. Cập nhật chỉ kích hoạt sau thao tác người chơi, không tự reload giữa gameplay.
3. “Để sau” chỉ ẩn trong phiên UI hiện tại; bản mới vẫn có thể mở lại sau reload.
4. Timeout/lỗi gửi update mở khóa retry và không xóa tiến trình.
5. Menu Hướng dẫn AW2 hiển thị trạng thái online/offline thực tế.
6. `online`/`offline` event cập nhật status không cần reload.
7. `beforeinstallprompt` được giữ cho thao tác cài đặt có chủ ý.
8. Nút cài PWA chỉ hiện khi prompt khả dụng; kết quả accepted/dismissed được phản ánh.
9. Standalone/appinstalled không tiếp tục mời cài.
10. UI hiển thị persistent-storage state và cho yêu cầu giữ dữ liệu khi browser hỗ trợ.
11. UI hiển thị usage/quota bằng số dễ đọc nhưng không coi Cache Storage là player save.
12. Client hỏi service worker về version, số entry/bytes media và số cache version giữ lại.
13. Service worker chỉ trả cache status qua `MessagePort`, không chạm localStorage/IndexedDB.
14. Install core lỗi phải xóa cache version cài dở trước khi fail.
15. Navigation offline ưu tiên shell hiện hành và fallback shell phiên bản trước.
16. Hashed chunk phiên bản trước vẫn phục vụ tab cũ; chỉ giữ tối đa một previous core/media version.
17. Media cache trim trước khi ghi để không vượt60MB/120entry rồi mới gặp quota.
18. Nếu `cache.put` vẫn báo quota, worker evict entry cũ và retry đúng một lần.
19. Manifest production có `id`/`scope`, shortcuts AW2/Rương, start/display/lang/icon contract được verify.
20. Focused/full unit, hai typecheck/build, package/release/assets/budget PASS; browser chạy nếu hạ tầng có, nếu thiếu ghi `NOT_RUN`.

## Phạm vi và rủi ro

- In scope: web PWA status/install/update UI, service-worker install/cache recovery, manifest contract, tests và hồ sơ production.
- Out of scope: đổi save/schema/gameplay/quest/economy/art/canon; native Capacitor update; deploy; đổi `master`/`rpg`.
- Rủi ro: auto-reload làm mất thao tác chưa lưu, cache cleanup xóa nhầm app khác, quota retry loop, install prompt sai trên iOS, tab cũ mất hashed chunk.
- Guard: chỉ cache prefix `som-web-*`; không xóa browser storage/player save; update vẫn explicit; fallback chỉ same-origin GET.
