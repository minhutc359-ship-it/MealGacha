Win returns to a safe Phòng Bàn position and persists the defeated flag; loss/retreat returns safely to Sân with prior quest flags and no victory. A failed settlement retains the live result for retry; no UI progression before successful write. Conflicts require reread/restart and never overwrite new save/reset identity.
