# Source and asset protection · 16 October 2026

Production build: minified JavaScript, sourcemap false, dist-only hosting; releaseGuard.mjs is a mandatory build/ZIP check. The browser receives executable JavaScript and necessary media. They can be inspected; obfuscation, disabled context menus and terms are not access control.

The GitHub repository was observed public during this update. The app integration available for this task does not provide repository visibility administration. The owner can use Repository Settings → General → Danger Zone → Change repository visibility, review the consequences, and select Private. Review collaborators and deployment integration access afterward. This cannot recall existing clones/forks/cache. Do not publish source ZIPs; source packages remain local ignored development artifacts.

Keep private keys and privileged logic on authenticated server infrastructure; do not put secrets in VITE_* variables. No server, private API or authentication is added by this visual update. If any credential was actually exposed in the past, revoke/rotate it with its provider; making a repository private would not invalidate it.

The policy and application license reserve only rights actually held and preserve third-party license rights and mandatory exceptions. No Riot/TFT code, models, animations, maps or music are added. The 13 unresolved asset records remain visible through `pnpm release:rights`; `pnpm release:commercial` blocks until evidence is reviewed or assets replaced. Ordinary preview builds remain available for review. Rights records do not certify non-infringement.
